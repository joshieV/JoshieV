## About

First year BSc Software Engineering at the University of Leicester, straight off the back of a Level 3 Extended Diploma in Computer Science.

Most of my time goes on Java and Python, with React on the front end. I build things mainly to find out how they actually work: a chat app to understand real-time messaging, a stopwatch to get comfortable with desktop UI, a deliberately useless calculator because it was funny. Alongside that I'm working through NeetCode most days and getting to grips with Spring Boot.

Open to internships, collaborations, and beginner-friendly open source.
